# UAT سبرنت 4 — الدليل الشجري ومحرك القيود والمحاسبة الفعلية

**الهدف:** محاسب حقيقي (لا مطوّر) يمر بهذه الخطوات على بيئة التطوير
(`http://<subdomain>.localhost:3000` أو الرابط المكافئ) بحساب Owner أو
Accountant، ويسجّل النتيجة الفعلية (✅/❌ + ملاحظة) في العمود الأخير —
أو في `docs/UAT_LOG.md` إن أراد تفصيلًا أطول لأي خطوة. أي "❌" يُوقف
إغلاق السبرنت حتى يُحل أو يُوثَّق كديْن تقني صريح في README.

**قبل البدء:** مستأجر تجريبي جديد (أو مستأجر Acme الحالي)، بنوع نشاط
"تجارية" (trading) عند التسجيل إن أمكن — لإتاحة قالب دليل حسابات أوسع
في الخطوة 1.

> **تنفيذ 2026-09-23 (انظر `docs/UAT_LOG.md` للتفاصيل الكاملة):** نُفِّذت
> كل الخطوات فعليًا ضد مستأجر "Fatma" الحقيقي عبر استدعاءات API مباشرة
> (بواسطة Claude Code، لا عبر واجهة المستخدم ولا بمحاسب بشري) — نتائج
> حقيقية من النظام الفعلي، لا افتراضية. هذا **يكمل، لا يُغني عن**، مرور
> محاسب حقيقي على نفس الخطوات عبر الواجهة فعليًا (تجربة الاستخدام،
> صحة التسميات المرئية، سلاسة النماذج — لا يقيسها اختبار API).
