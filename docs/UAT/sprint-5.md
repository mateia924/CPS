# UAT سبرنت 5 — السندات وفرق العملة المحقق والمرفقات كدليل إثبات

**الهدف:** محاسب حقيقي (لا مطوّر) يمر بهذه الخطوات على بيئة التطوير
(`http://<subdomain>.localhost:3000` أو الرابط المكافئ) بحساب Owner أو
Accountant، ويسجّل النتيجة الفعلية (✅/❌ + ملاحظة) في العمود الأخير —
أو في `docs/UAT_LOG.md` إن أراد تفصيلًا أطول لأي خطوة. أي "❌" يُوقف
إغلاق السبرنت حتى يُحل أو يُوثَّق كديْن تقني صريح في README.

**قبل البدء:** مستأجر به بنك وصندوق نقدية مسجَّلان (الخزينة ← البنوك/
الصناديق)، عميل واحد على الأقل، سعر صرف USD→SAR مسجَّل بتاريخ اليوم
(الخزينة ← أسعار الصرف)، وموظف واحد مسجَّل بدور "موظف" (لخطوة العهدة).
**ملاحظة منهجية (خلافًا لسبرنت 4):** هذا السكربت لم يُنفَّذ عبر API
مسبقًا في هذه الدورة — عمود "النتيجة" أدناه فارغ عمدًا بانتظار محاسب
بشري فعلي، انظر `docs/UAT_LOG.md`.
